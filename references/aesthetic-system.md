# Aesthetic system

Use this reference to phrase a returned final plan in visible, natural photographic language. The composer pool is only a set of defaults: user locks, reference controls, and custom natural-language bias values may be outside it. Never replace a final field while rendering. User locks always win.

## Twelve dimensions

Compatibility tags describe useful affinities rather than extra requirements: `wide`, `normal`, `tele`, `distant`, `full`, `medium`, `close`, `moving`, `still`, `outdoor`, `interior`, `day`, `dusk`, `night`, and `layered`.

| Dimension / composer key | Options and useful directions | Compatibility notes |
|---|---|---|
| 表情 `expression` | 自然微笑；专注侧望；放松平静；回眸一瞬；说话未完、短暂走神、被环境吸引 | 回眸一瞬 pairs with `moving`; subtle expression protects identity better than extreme grimaces. |
| 服装 `wardrobe` | 亚麻衬衫与半身裙；针织上衣与牛仔裤；轻薄连衣裙；宽松风衣；可见的轮廓、材质、覆盖度、颜色与松紧关系 | Describe visible construction, not a trend label alone. Long hems need plausible movement and ground clearance. |
| 场景 `scene` | 盛夏荷塘；街角咖啡店；旧书店窗边；傍晚海堤；花店工作台、雨后店门、公交车厢、便利店门口等 lived-in spaces | Tag as `outdoor`/`interior` and `day`/`dusk`; preserve functional objects and ordinary clutter. |
| 进行中动作 `action` | 整理发梢；缓步前行；翻阅书页；望向远处；收伞、扎花、推门、递物、整理衣角 | Prefer an unfinished verb plus a small consequence: fabric shift, lifted heel, water drops, or displaced object. |
| 景别 `shot_distance` | 全身；中景；近景；特写；环境人像、半身 | Full-body actions need adequate camera distance; identity-high work favors medium or close views unless locked otherwise. |
| 焦段 `lens` | 28mm广角；50mm标准；85mm中长焦；200mm长焦；35mm纪实广角 | `wide` supports environmental proximity; `tele` needs distance and compression. A lens is not permission to contradict the requested framing. |
| 机位 `camera_angle` | 平视；低机位仰拍；高机位俯拍；侧后方跟拍；贴近桌面、门后偷看、隔窗、肩后、地面附近 | State the photographer's physical position and viewing direction. Extreme proximity or distortion consumes identity budget. |
| 构图 `composition` | 三分法留白；中央对称；框景构图；对角线构图；边缘切入、偏心主体、负空间、镜面分层 | Favor an unusual but readable relationship among subject, frame edge, environment, and depth. Avoid default centered portrait staging unless locked. |
| 前景 `foreground` | 荷叶虚化前景；玻璃反光前景；枝叶遮挡前景；无明显前景；门框、路人肩部、桌沿、花束、雨伞边缘 | A visible intrusion should enter from a named edge and create `layered` depth. It must not cover protected identity anchors. |
| 光线 `lighting` | 柔和阴天光；午后侧逆光；室内窗边漫射光；傍晚金色侧光；招牌混合光、雨后反射光 | Match time and source direction to the scene. Mixed light stays believable when each source has a visible origin. |
| 色彩 `color_scheme` | 低饱和青绿与米白；暖棕与墨蓝；灰粉与奶油白；日落橙与深蓝；从 wardrobe/environment 提取克制色组 | Name exactly 3–4 dominant color blocks and their carriers, such as 墨绿风衣、暖灰墙面、暗红招牌、肤色高光. |
| 摄影状态 `photography_state` | 自然抓拍颗粒感；轻微运动模糊；真实胶片质感；纪实瞬间感；偶发反光、轻微倾斜、边缘切裁、真实肤理 | Imperfections must be localized and plausible. Keep the face, identity anchors, and essential garment structure legible. |

The composer applies these tags before returning final plans:

- Scenes: 盛夏荷塘 `[outdoor, day]`; 街角咖啡店 `[outdoor, day/dusk]`; 旧书店窗边 `[interior, day]`; 傍晚海堤 `[outdoor, dusk]`.
- Actions: 整理发梢 `[still, close/medium]`; 缓步前行 `[moving, full/medium]`; 翻阅书页 `[still, close/medium]`; 回头、收伞、推门 `[moving, medium/full]`.
- Lenses and distance: 28mm `[wide, full/medium]`; 35mm `[wide, full/medium]`; 50mm `[normal, medium/close]`; 85mm `[tele, medium/close]`; 200mm `[tele, distant, close/medium]`.
- Camera and depth: 贴近桌面、门后、隔窗、肩后、地面附近 pair with `[layered]`; glass, leaves, doorframes, passersby, and tabletop edges are `[layered]` foreground sources.
- Light: 柔和阴天光 `[day]`; 午后侧逆光 `[day]`; 室内窗边漫射光 `[interior, day]`; 傍晚金色侧光 `[dusk]`; motivated sign light `[dusk/night]`.

## Translate fashion labels into visible evidence

Never rely on an ambiguous internet style label by itself. Retain a user-supplied label as context, then independently spell out its visible traits; do not infer ethnicity, age, personality, body type, or brand.

| Label | Visible-language mapping |
|---|---|
| 韩系 / Korean INS | clean relaxed silhouette; fine knit, cotton, or washed denim; moderate coverage; cream, soft gray, faded blue; one gently oversized layer |
| Clean fit | straight uncluttered silhouette; smooth matte fabric; full or moderate coverage; white, charcoal, navy; precise but non-tight fit |
| 老钱 / quiet luxury | restrained tailored silhouette; wool, cashmere, linen, or leather accents; moderate coverage; camel, ivory, navy, forest green; relaxed structure without visible logos |
| 法式复古 | softly defined waist with simple neckline; cotton, linen, or small-scale textured fabric; moderate coverage; cream, muted red, faded blue; easy rather than costume-like fit |
| Y2K | cropped or fitted top balanced by wider low-rise or cargo silhouette; rib knit, denim, or light technical fabric; user-specified coverage; silver, icy blue, black; one recognizable period detail |
| 辣妹风 | fitted silhouette balanced by one looser layer; stretch knit, denim, or leather accent; state coverage explicitly instead of assuming it; black plus one saturated color; body-skimming rather than identity-changing |
| 通勤风 | neat straight or lightly tailored silhouette; shirting, fine knit, twill; moderate coverage; stone, navy, pale blue; comfortable structured fit |

If a label and explicit garment details disagree, the explicit details are the lock and the label is only mood context.

## Compatibility and identity budget

- Treat only physical impossibility as a hard conflict. Example: a locked 200mm lens, 30 cm camera distance, and full-body framing cannot all be honestly claimed.
- The pre-return compatibility loop preserves every lock and reference-controlled field. It deterministically repairs only unprotected fields, records each replacement in `repairs`, and repeats the complete rule set after any mutation until the plan is stable within a fixed bound.
- The loop rejects indoor window light at the lotus pond or sea wall, keeps page-turning in a plausible reading location, motivates lotus leaves and glass foregrounds from the scene, aligns standard lens/shot-distance pairs, and avoids a following-camera position without movement. These are concrete compatibility rules, not permission for a renderer to improvise replacements.
- With `identity_policy: high`, the loop keeps face shape, feature proportions, hairline, signature accessories, and body proportions readable. It replaces unprotected obstructing branches, close extreme camera angles, wide close-up distortion, and blur that threatens identity anchors. If an unsafe value is protected, it stays unchanged and produces a warning for user resolution.
- A separate final invariant check runs after the loop. Any protected conflict, non-convergence, or remaining incompatibility is reported in `warnings`; the composer never silently returns an incompatible plan as successful.
- Feasible aesthetic tension may remain only when it is already expressed by the final plan. Rendering may explain that value naturally but cannot add a new camera relationship or workaround.

## Natural-language assembly

Assemble in this order from the returned plan: aspect ratio → subject and identity anchors → expression → visible wardrobe → scene → in-progress action → shot distance and lens → photographer position and camera angle → composition → foreground intrusion → lighting → 3–4 dominant color blocks → photography state → only necessary negative constraints.

The result should read as one shootable moment. Preserve ordinary motion, spatial layers, unusual composition, and restrained color. Describe a photographer who encountered the moment in a functional location with motivated light, natural skin and fabric, and small incidental irregularities. Use seamless-studio, beauty-light, catalog-pose, or clinically perfect campaign language only when the user explicitly asks for it.
